One sentence of at most 200 characters explaining the modern internet to
someone arriving from 1800, built only from things they already know: a road,
a post office, a library, a market, a letter. The program writes the sentence
to `/output/entry.txt` for the make.fun judge to compare against other entries.

## Run

```sh
python3 main.py
```

It writes one sentence (175 characters) to `/output/entry.txt`, or to
`$OUTPUT_DIR/entry.txt` when that is set. Python 3.13, standard library only,
deterministic, no network.

## The sentence

Think of one road joining every post office, library, and market on earth, so
a letter you write arrives before the ink dries and any stranger may answer
it by return of post.
